# WIN-021 Defenderリアルタイム保護の無効化

DefenderのOperationalチャネルでリアルタイム保護停止イベントを検知。

|項目|内容|
|---|---|
|対象ログ|Windows Event|
|必要フィールド|`_time`, `log_type`, `channel`, `event_id`, `host`|
|ATT&CK 戦術|[TA0112 Defense Impairment](https://attack.mitre.org/tactics/TA0112)|
|技法 → サブ技法|[T1685 Disable or Modify Tools](https://attack.mitre.org/techniques/T1685)|
|検索|5分窓／5分間隔／5分遅延|
|工夫|プロセス引数の推測に加え、製品側で記録された保護停止を観測。|

Defender Operationalチャネルを収集。

## SPL

```spl
index=detection_lab log_type="windows" earliest=-10m@m latest=-5m@m
| where channel="Microsoft-Windows-Windows Defender/Operational"
    AND event_id=5001
| stats count as observed
        min(_time) as first_seen
        max(_time) as last_seen
    by host
| eval rule_id="WIN-021", attack_id="T1685"
```

**範囲：** 製品更新や管理操作も一致。5001単独では操作主体は分からない。
