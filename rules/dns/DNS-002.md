# DNS-002 多様な名前への継続的なNXDOMAIN探索

15分で50種類以上の名前が失敗し、失敗率80%以上・名前多様性70%以上。失敗は3分区間以上に分散し、単一名への偏りは10%以下。

|項目|内容|
|---|---|
|対象ログ|DNS|
|必要フィールド|`_time`, `log_type`, `src_ip`, `dns_query`, `rcode`|
|ATT&CK 戦術|[TA0011 Command and Control](https://attack.mitre.org/tactics/TA0011)|
|技法 → サブ技法|[T1568 Dynamic Resolution](https://attack.mitre.org/techniques/T1568) → [T1568.002 Domain Generation Algorithms](https://attack.mitre.org/techniques/T1568/002)|
|検索|15分窓／5分間隔／5分遅延|
|工夫|名前別→端末別の二段集約で再試行集中と名前探索を区別。複数の分区間での発生を要求。|

rcodeは文字列NXDOMAIN等。数値コードは正規化する。

## SPL

```spl
index=detection_lab log_type="dns" earliest=-20m@m latest=-5m@m
| eval query=lower(rtrim(dns_query,".")), reply=upper(rcode),
       minute=floor(_time/60)
| where NOT match(query,"[.]arpa$")
| stats count as queries
        sum(eval(if(reply="NXDOMAIN",1,0))) as failures
        values(eval(if(reply="NXDOMAIN",minute,null()))) as failure_minutes
        min(_time) as first_seen
        max(_time) as last_seen
    by src_ip query
| stats sum(queries) as queries
        sum(failures) as failed
        count(eval(failures > 0)) as failed_names
        max(failures) as most_repeated_failure
        values(failure_minutes) as failure_minutes
        min(first_seen) as first_seen
        max(last_seen) as last_seen
    by src_ip
| eval failure_ratio=failed/queries,
       name_diversity=failed_names/max(failed,1),
       top_name_share=most_repeated_failure/max(failed,1),
       active_minutes=mvcount(failure_minutes)
| where failed_names >= 50 AND failure_ratio >= 0.8
    AND name_diversity >= 0.7 AND top_name_share <= 0.1
    AND active_minutes >= 3
| eval rule_id="DNS-002", attack_id="T1568.002"
```

**範囲：** ランダム名を使う正常ソフトや設定不備でも一致。再試行の多いDGA・短時間活動は漏れる。リゾルバ集約後のIPでは端末を識別できない。

**調査：** 失敗名と同時刻の成功名を確認し、成功名への後続通信をFW／Proxyで追う。全端末一斉ならDNS障害やソフト更新も確認する。
