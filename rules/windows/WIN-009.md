# WIN-009 ドメイン特権グループへのメンバー追加

Domain Admins・Schema Admins・Enterprise Adminsへの追加をSIDで識別。

|項目|内容|
|---|---|
|対象ログ|Windows Event|
|必要フィールド|`_time`, `log_type`, `channel`, `event_id`, `host`, `TargetSid`, `MemberSid`, `SubjectUserName`|
|ATT&CK 戦術|[TA0003 Persistence](https://attack.mitre.org/tactics/TA0003), [TA0004 Privilege Escalation](https://attack.mitre.org/tactics/TA0004)|
|技法 → サブ技法|[T1098 Account Manipulation](https://attack.mitre.org/techniques/T1098) → [T1098.007 Additional Local or Domain Groups](https://attack.mitre.org/techniques/T1098/007)|
|検索|5分窓／5分間隔／5分遅延|
|工夫|WIN-004の組み込みローカルグループに加え、ドメイン側の特権追加を観測。|

DCの4728/4756成功監査。

## SPL

```spl
index=detection_lab log_type="windows" earliest=-10m@m latest=-5m@m
| where channel="Security" AND event_id IN (4728,4756)
    AND match(TargetSid, "^S-1-5-21-\\d+-\\d+-\\d+-(512|518|519)$")
| stats count as observed
        min(_time) as first_seen
        max(_time) as last_seen
    by host TargetSid MemberSid SubjectUserName
| eval rule_id="WIN-009", attack_id="T1098.007"
```

**範囲：** グループ名の言語差に依存しないが、別の特権グループは対象外。
