# WIN-022 非コンピュータアカウントによるディレクトリ複製権限利用

4662で複製関連権限の利用を記録し、主体が末尾$の機械アカウントでない。

|項目|内容|
|---|---|
|対象ログ|Windows Event|
|必要フィールド|`_time`, `log_type`, `channel`, `event_id`, `host`, `SubjectUserName`, `SubjectLogonId`, `Properties`, `AccessMask`|
|ATT&CK 戦術|[TA0006 Credential Access](https://attack.mitre.org/tactics/TA0006)|
|技法 → サブ技法|[T1003 OS Credential Dumping](https://attack.mitre.org/techniques/T1003) → [T1003.006 DCSync](https://attack.mitre.org/techniques/T1003/006)|
|検索|5分窓／5分間隔／5分遅延|
|工夫|監査イベントに複製権限GUIDとControl Accessビットを組み合わせる。|

DCのDirectory Service Access成功監査とドメインNCのSACLが必要。

## SPL

```spl
index=detection_lab log_type="windows" earliest=-10m@m latest=-5m@m
| where channel="Security" AND event_id=4662
    AND NOT match(SubjectUserName, "\\$$")
    AND bit_and(tonumber(replace(lower(AccessMask),"^0x",""),16),256)=256
    AND match(Properties, "(?i)(1131f6ad-9c07-11d1-f79f-00c04fc2dcd2|89e95b76-444d-4c62-991a-0facbeda640c)")
| stats count as observed
        min(_time) as first_seen
        max(_time) as last_seen
    by host SubjectUserName SubjectLogonId
| eval rule_id="WIN-022", attack_id="T1003.006"
```

**範囲：** 正規同期サービスも一致。マシンアカウントを使うDCSyncは対象外。
