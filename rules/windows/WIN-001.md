# WIN-001 EncodedCommandを使うPowerShell

PowerShellのエンコード引数を検知。

|項目|内容|
|---|---|
|対象ログ|Windows Event|
|必要フィールド|`_time`, `channel`, `command_line`, `event_id`, `host`, `log_type`, `process_path`|
|ATT&CK 戦術|[TA0002 Execution](https://attack.mitre.org/tactics/TA0002)|
|技法 → サブ技法|[T1059 Command and Scripting Interpreter](https://attack.mitre.org/techniques/T1059) → [T1059.001 PowerShell](https://attack.mitre.org/techniques/T1059/001)|

## SPL

```spl
index=detection_lab log_type="windows" earliest=-10m@m latest=-5m@m
| where channel="Security"
    AND event_id=4688
    AND match(process_path, "(?i)(^|[\\\\/])(powershell|pwsh)\\.exe$")
    AND match(command_line, "(?i)(^|\\s)-(e|en|enc|enco|encod|encode|encoded|encodedc|encodedco|encodedcom|encodedcomm|encodedcomma|encodedcomman|encodedcommand)\\s+\\S+")
| stats count as observed
        min(_time) as first_seen
        max(_time) as last_seen
    by host
| where observed >= 1
| eval rule_id="WIN-001", attack_id="T1059.001"
```

**範囲：** コマンドライン収集が必要。名前変更・別表記は対象外。
