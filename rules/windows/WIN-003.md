# WIN-003 同一送信元・利用者への認証失敗集中

同一端末・送信元・ユーザーへの認証失敗が5分で10回以上。

|項目|内容|
|---|---|
|対象ログ|Windows Event|
|必要フィールド|`_time`, `channel`, `event_id`, `host`, `log_type`, `src_ip`, `user`|
|ATT&CK 戦術|[TA0006 Credential Access](https://attack.mitre.org/tactics/TA0006)|
|技法 → サブ技法|[T1110 Brute Force](https://attack.mitre.org/techniques/T1110) → [T1110.001 Password Guessing](https://attack.mitre.org/techniques/T1110/001)|

## SPL

```spl
index=detection_lab log_type="windows" earliest=-10m@m latest=-5m@m
| where channel="Security"
    AND event_id=4625
    AND match(src_ip, "^(?!-$).+")
    AND match(user, "^(?!-$).+")
| stats count as observed
        min(_time) as first_seen
        max(_time) as last_seen
    by host src_ip user
| where observed >= 10
| eval rule_id="WIN-003", attack_id="T1110.001"
```

**範囲：** 低速・分散試行、4625以外の認証失敗は対象外。
