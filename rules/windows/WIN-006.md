# WIN-006 複数ユーザーへの低回数パスワード試行

同一送信元から15分で10ユーザー以上に失敗し、各ユーザーへの試行は5回以下。

|項目|内容|
|---|---|
|対象ログ|Windows Event|
|必要フィールド|`_time`, `log_type`, `channel`, `event_id`, `host`, `src_ip`, `user`|
|ATT&CK 戦術|[TA0006 Credential Access](https://attack.mitre.org/tactics/TA0006)|
|技法 → サブ技法|[T1110 Brute Force](https://attack.mitre.org/techniques/T1110) → [T1110.003 Password Spraying](https://attack.mitre.org/techniques/T1110/003)|
|検索|15分窓／5分間隔／5分遅延|
|工夫|WIN-003の単一ユーザー集中と分け、対象ユーザーの広がりを判定。|

## SPL

```spl
index=detection_lab log_type="windows" earliest=-20m@m latest=-5m@m
| where channel="Security" AND event_id=4625
    AND src_ip!="-" AND user!="-"
| stats count as attempts
        min(_time) as first_seen
        max(_time) as last_seen
    by host src_ip user
| stats dc(user) as targeted_users
        sum(attempts) as failures
        max(attempts) as max_per_user
        min(first_seen) as first_seen
        max(last_seen) as last_seen
    by host src_ip
| where targeted_users >= 10 AND max_per_user <= 5
| eval rule_id="WIN-006", attack_id="T1110.003"
```

**範囲：** 共有NATや認証ゲートウェイでも一致。userはドメイン付きの対象ユーザー。
