# WIN-003 同一送信元・利用者への認証失敗集中

- 状態：experimental / 重要度：medium
- ATT&CK：T1110.001 / credential-access
- 対象ログ：windows
- 必須フィールド：_time, channel, event_id, host, log_type, src_ip, user
- 窓：300秒（検索範囲全体） / 集約：host, src_ip, user
- 指標：count（count以外は異なる値の数） / 閾値：10以上

## 採取の前提

Audit Logon Failure。IpAddressとTargetUserNameを正規化。重複イベントを除去。

## 誤検知と調整

古いパスワードのサービス、入力ミス、共有NAT。

## 調査

Status/SubStatus、LogonType、後続4624、送信元資産を確認。

## 限界

5分10回は初期値。低速攻撃、複数ユーザーへのスプレー、IP欠損、4771/4776だけの失敗は対象外。

## 条件（すべてAND）

```json
[
  [
    "channel",
    "eq",
    "Security"
  ],
  [
    "event_id",
    "eq",
    4625
  ],
  [
    "src_ip",
    "regex",
    "^(?!-$).+"
  ],
  [
    "user",
    "regex",
    "^(?!-$).+"
  ]
]
```
