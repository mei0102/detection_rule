# WIN-016 Officeから起動したMSHTAがURLを指定

Officeプロセスの子として起動したmshtaがHTTP(S)を参照する。

|項目|内容|
|---|---|
|対象ログ|Windows Event|
|必要フィールド|`_time`, `log_type`, `channel`, `event_id`, `host`, `process_path`, `command_line`, `ParentProcessName`|
|ATT&CK 戦術|[TA0005 Stealth](https://attack.mitre.org/tactics/TA0005)|
|技法 → サブ技法|[T1218 System Binary Proxy Execution](https://attack.mitre.org/techniques/T1218) → [T1218.005 Mshta](https://attack.mitre.org/techniques/T1218/005)|
|検索|5分窓／5分間隔／5分遅延|
|工夫|URL指定だけでなくOfficeからの親子関係を追加。|

ParentProcessNameは4688のCreator Process Nameを抽出。

## SPL

```spl
index=detection_lab log_type="windows" earliest=-10m@m latest=-5m@m
| where channel="Security" AND event_id=4688
    AND match(process_path, "(?i)(^|[\\\\/])mshta\\.exe$")
    AND match(command_line, "(?i)https?://")
    AND match(ParentProcessName, "(?i)(^|[\\\\/])(winword|excel|powerpnt|outlook)\\.exe$")
| stats count as observed
        min(_time) as first_seen
        max(_time) as last_seen
        values(ParentProcessName) as parents values(command_line) as commands
    by host
| eval rule_id="WIN-016", attack_id="T1218.005"
```

**範囲：** 親名が収集されない4688では使えない。Office以外の起動は対象外。
