# WIN-024 管理共有への実行形式の書込み権限チェック

ADMIN$／C$共有の実行形式に対しWriteData権限を要求するアクセス。

|項目|内容|
|---|---|
|対象ログ|Windows Event|
|必要フィールド|`_time`, `log_type`, `channel`, `event_id`, `host`, `src_ip`, `SubjectUserName`, `ShareName`, `RelativeTargetName`, `AccessMask`|
|ATT&CK 戦術|[TA0008 Lateral Movement](https://attack.mitre.org/tactics/TA0008)|
|技法 → サブ技法|[T1570 Lateral Tool Transfer](https://attack.mitre.org/techniques/T1570)|
|検索|5分窓／5分間隔／5分遅延|
|工夫|5140の共有アクセスから、5145の対象ファイルと書込権限へ具体化。|

Audit Detailed File Share。元ログのAccessMaskを16進文字列で保持。

## SPL

```spl
index=detection_lab log_type="windows" earliest=-10m@m latest=-5m@m
| where channel="Security" AND event_id=5145
    AND match(ShareName, "(?i)(^|[\\\\/])(ADMIN|C)\\$$")
    AND match(RelativeTargetName, "(?i)\\.(exe|dll|ps1|bat|cmd)$")
    AND bit_and(tonumber(replace(lower(AccessMask),"^0x",""),16),2)=2
| stats count as observed
        min(_time) as first_seen
        max(_time) as last_seen
        values(RelativeTargetName) as requested_files
    by host src_ip SubjectUserName
| eval rule_id="WIN-024", attack_id="T1570"
```

**範囲：** 5145はアクセスチェックで、書込み完了を証明しない。正規配布も一致。
