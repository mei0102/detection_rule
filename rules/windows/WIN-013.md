# WIN-013 comsvcsを使ったプロセスメモリのダンプ

rundll32がcomsvcsのMiniDump機能をPID指定で呼び出す。

|項目|内容|
|---|---|
|対象ログ|Windows Event|
|必要フィールド|`_time`, `log_type`, `channel`, `event_id`, `host`, `process_path`, `command_line`|
|ATT&CK 戦術|[TA0006 Credential Access](https://attack.mitre.org/tactics/TA0006)|
|技法 → サブ技法|[T1003 OS Credential Dumping](https://attack.mitre.org/techniques/T1003) → [T1003.001 LSASS Memory](https://attack.mitre.org/techniques/T1003/001)|
|検索|5分窓／5分間隔／5分遅延|
|工夫|DLL名だけでなくエクスポート名とPID引数を条件化。|

4688のコマンドライン収集。

## SPL

```spl
index=detection_lab log_type="windows" earliest=-10m@m latest=-5m@m
| where channel="Security" AND event_id=4688
    AND match(process_path, "(?i)(^|[\\\\/])rundll32\\.exe$")
    AND match(command_line, "(?i)comsvcs\\.dll\\s*,\\s*(MiniDump|#24)\\s+\\d+\\s+")
| stats count as observed
        min(_time) as first_seen
        max(_time) as last_seen
        values(command_line) as commands
    by host
| eval rule_id="WIN-013", attack_id="T1003.001"
```

**範囲：** LSASSのPIDかは判定しないため、資格情報ダンプの候補。
