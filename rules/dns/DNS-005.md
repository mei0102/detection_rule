# DNS-005 複数ゾーンへの転送要求

同じ送信元から同じDNSサーバに、15分で3ゾーン以上のAXFR／IXFR要求。

|項目|内容|
|---|---|
|対象ログ|DNS|
|必要フィールド|`_time`, `log_type`, `src_ip`, `dest_ip`, `dns_query`, `query_type`|
|ATT&CK 戦術|[TA0043 Reconnaissance](https://attack.mitre.org/tactics/TA0043)|
|技法 → サブ技法|[T1590 Gather Victim Network Information](https://attack.mitre.org/techniques/T1590) → [T1590.002 DNS](https://attack.mitre.org/techniques/T1590/002)|
|検索|15分窓／5分間隔／5分遅延|
|工夫|転送エラーだけでなく、DNSログで要求対象ゾーンの広がりを観測。|

DNSトランザクション単位でquery_typeをAXFR/IXFRへ正規化。

## SPL

```spl
index=detection_lab log_type="dns" earliest=-20m@m latest=-5m@m
| where upper(query_type) IN ("AXFR","IXFR")
| eval zone=lower(rtrim(dns_query,"."))
| stats dc(zone) as zones
        count as requests
        min(_time) as first_seen
        max(_time) as last_seen
    by src_ip dest_ip
| where zones >= 3
| eval rule_id="DNS-005", attack_id="T1590.002"
```

**範囲：** 正規セカンダリDNSも一致。ゾーン転送の成功は判断しない。
