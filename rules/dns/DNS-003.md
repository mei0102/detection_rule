# DNS-003 TXT応答にダウンロード・実行の文字列

TXT応答にHTTP(S) URLとスクリプト評価・コマンド実行の文字列が同居。

|項目|内容|
|---|---|
|対象ログ|DNS|
|必要フィールド|`_time`, `log_type`, `src_ip`, `dns_query`, `query_type`, `answer`|
|ATT&CK 戦術|[TA0011 Command and Control](https://attack.mitre.org/tactics/TA0011)|
|技法 → サブ技法|[T1071 Application Layer Protocol](https://attack.mitre.org/techniques/T1071) → [T1071.004 DNS](https://attack.mitre.org/techniques/T1071/004)|
|検索|5分窓／5分間隔／5分遅延|
|工夫|TXTの単語一致にURLとの組み合わせを加え、応答側の命令候補を抽出。|

query_type=TXT、answerは応答TXT文字列または複数値。

## SPL

```spl
index=detection_lab log_type="dns" earliest=-10m@m latest=-5m@m
| where upper(query_type)="TXT"
| eval response=mvjoin(answer," ")
| where match(response, "(?i)https?://")
    AND match(response, "(?i)(\\bInvoke-Expression\\b|\\biex\\b|cmd\\.exe\\s+/c|powershell\\s+-)")
| stats count as observed
        min(_time) as first_seen
        max(_time) as last_seen
    by src_ip dns_query
| eval rule_id="DNS-003", attack_id="T1071.004"
```

**範囲：** TXT応答本文が必要。符号化された指示は見逃し、実行済みとは判定しない。
