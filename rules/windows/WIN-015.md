# WIN-015 Regsvr32でリモートScriptletを指定

Regsvr32がscrobj.dllとHTTP(S)の/i引数を同時に指定する。

|項目|内容|
|---|---|
|対象ログ|Windows Event|
|必要フィールド|`_time`, `log_type`, `channel`, `event_id`, `host`, `process_path`, `command_line`|
|ATT&CK 戦術|[TA0005 Stealth](https://attack.mitre.org/tactics/TA0005)|
|技法 → サブ技法|[T1218 System Binary Proxy Execution](https://attack.mitre.org/techniques/T1218) → [T1218.010 Regsvr32](https://attack.mitre.org/techniques/T1218/010)|
|検索|5分窓／5分間隔／5分遅延|
|工夫|scrobjの指定だけでなく、リモートのインストール引数に限定。|

4688のコマンドライン収集。

## SPL

```spl
index=detection_lab log_type="windows" earliest=-10m@m latest=-5m@m
| where channel="Security" AND event_id=4688
    AND match(process_path, "(?i)(^|[\\\\/])regsvr32\\.exe$")
    AND match(command_line, "(?i)\\bscrobj\\.dll\\b")
    AND match(command_line, "(?i)(^|\\s)[-/]i:\\s*\"?https?://")
| stats count as observed
        min(_time) as first_seen
        max(_time) as last_seen
        values(command_line) as commands
    by host
| eval rule_id="WIN-015", attack_id="T1218.010"
```

**範囲：** ローカルScriptletや別表記は対象外。登録の成功は判断しない。
