# DNS-001 長いDNSラベルを持つ多数の異なる問い合わせ

50〜63文字のDNSラベルを含む問い合わせが5分で20種類以上。

|項目|内容|
|---|---|
|対象ログ|DNS|
|必要フィールド|`_time`, `dns_query`, `log_type`, `src_ip`|
|ATT&CK 戦術|[TA0011 Command and Control](https://attack.mitre.org/tactics/TA0011)|
|技法 → サブ技法|[T1071 Application Layer Protocol](https://attack.mitre.org/techniques/T1071) → [T1071.004 DNS](https://attack.mitre.org/techniques/T1071/004)|

## SPL

```spl
index=detection_lab log_type="dns" earliest=-10m@m latest=-5m@m
| where match(dns_query, "(^|\\.)[^.]{50,63}(\\.|$)")
| stats dc(dns_query) as observed
        min(_time) as first_seen
        max(_time) as last_seen
    by src_ip
| where observed >= 20
| eval rule_id="DNS-001", attack_id="T1071.004"
```

**範囲：** 問い合わせ名と送信元を記録したDNSログが必要。短いラベルは対象外。
