# WIN-025 WinRM配下で転送ツールを起動

wsmprovhostを親に、CertUtil／BITSAdmin／MSHTAがHTTP(S)を指定して起動。

|項目|内容|
|---|---|
|対象ログ|Windows Event|
|必要フィールド|`_time`, `log_type`, `channel`, `event_id`, `host`, `ParentProcessName`, `process_path`, `command_line`|
|ATT&CK 戦術|[TA0008 Lateral Movement](https://attack.mitre.org/tactics/TA0008)|
|技法 → サブ技法|[T1021 Remote Services](https://attack.mitre.org/techniques/T1021) → [T1021.006 Windows Remote Management](https://attack.mitre.org/techniques/T1021/006)|
|検索|5分窓／5分間隔／5分遅延|
|工夫|WinRMのシェル起動全般ではなく、転送ツールとURL指定の組み合わせ。|

4688の親プロセス名・コマンドラインを収集。

## SPL

```spl
index=detection_lab log_type="windows" earliest=-10m@m latest=-5m@m
| where channel="Security" AND event_id=4688
    AND match(ParentProcessName, "(?i)(^|[\\\\/])wsmprovhost\\.exe$")
    AND match(process_path, "(?i)(^|[\\\\/])(certutil|bitsadmin|mshta)\\.exe$")
    AND match(command_line, "(?i)https?://")
| stats count as observed
        min(_time) as first_seen
        max(_time) as last_seen
        values(process_path) as tools values(command_line) as commands
    by host
| eval rule_id="WIN-025", attack_id="T1021.006"
```

**範囲：** 正規のリモート配布も一致。親名のない4688では検知できない。
