# WIN-019 復元用シャドウコピーの一括削除指定

vssadminの全コピー削除、またはwmicのshadowcopy削除を検知。

|項目|内容|
|---|---|
|対象ログ|Windows Event|
|必要フィールド|`_time`, `log_type`, `channel`, `event_id`, `host`, `process_path`, `command_line`|
|ATT&CK 戦術|[TA0040 Impact](https://attack.mitre.org/tactics/TA0040)|
|技法 → サブ技法|[T1490 Inhibit System Recovery](https://attack.mitre.org/techniques/T1490)|
|検索|5分窓／5分間隔／5分遅延|
|工夫|バックアップの表示・作成と分け、削除操作の引数を判定。|

4688のコマンドライン収集。

## SPL

```spl
index=detection_lab log_type="windows" earliest=-10m@m latest=-5m@m
| where channel="Security" AND event_id=4688
    AND ((match(process_path, "(?i)(^|[\\\\/])vssadmin\\.exe$")
          AND match(command_line, "(?i)\\bdelete\\s+shadows\\b")
          AND match(command_line, "(?i)(^|\\s)/all(\\s|$)"))
      OR (match(process_path, "(?i)(^|[\\\\/])wmic\\.exe$")
          AND match(command_line, "(?i)\\bshadowcopy\\b.*\\bdelete\\b")))
| stats count as observed
        min(_time) as first_seen
        max(_time) as last_seen
        values(command_line) as commands
    by host
| eval rule_id="WIN-019", attack_id="T1490"
```

**範囲：** 正規の復元領域整理も一致。コピー削除の成否は判断しない。
