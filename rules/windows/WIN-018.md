# WIN-018 PowerShellスクリプト内の取得と動的実行

同じスクリプトブロックにHTTP取得とInvoke-Expressionが記録される。

|項目|内容|
|---|---|
|対象ログ|Windows Event|
|必要フィールド|`_time`, `log_type`, `channel`, `event_id`, `host`, `ScriptBlockId`, `ScriptBlockText`|
|ATT&CK 戦術|[TA0002 Execution](https://attack.mitre.org/tactics/TA0002)|
|技法 → サブ技法|[T1059 Command and Scripting Interpreter](https://attack.mitre.org/techniques/T1059) → [T1059.001 PowerShell](https://attack.mitre.org/techniques/T1059/001)|
|検索|5分窓／5分間隔／5分遅延|
|工夫|プロセス引数からスクリプト本文へ観測を広げ、取得と評価の同居を判定。|

PowerShell Script Block Loggingの4104が必要。

## SPL

```spl
index=detection_lab log_type="windows" earliest=-10m@m latest=-5m@m
| where channel="Microsoft-Windows-PowerShell/Operational" AND event_id=4104
    AND match(ScriptBlockText, "(?i)(DownloadString|Invoke-WebRequest|Invoke-RestMethod|\\biwr\\b|\\birm\\b)")
    AND match(ScriptBlockText, "(?i)(\\bInvoke-Expression\\b|\\biex\\b)")
    AND match(ScriptBlockText, "(?i)https?://")
| stats count as observed
        min(_time) as first_seen
        max(_time) as last_seen
    by host ScriptBlockId
| eval rule_id="WIN-018", attack_id="T1059.001"
```

**範囲：** 分割された4104を再構成しないため、別断片・別変数に分かれると見逃す。
