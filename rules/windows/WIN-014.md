# WIN-014 CertUtilでHTTPファイル取得を指定

CertUtilのURLキャッシュ・CTL取得系オプションとHTTP(S) URLが同時に現れる。

|項目|内容|
|---|---|
|対象ログ|Windows Event|
|必要フィールド|`_time`, `log_type`, `channel`, `event_id`, `host`, `process_path`, `command_line`|
|ATT&CK 戦術|[TA0011 Command and Control](https://attack.mitre.org/tactics/TA0011)|
|技法 → サブ技法|[T1105 Ingress Tool Transfer](https://attack.mitre.org/techniques/T1105)|
|検索|5分窓／5分間隔／5分遅延|
|工夫|プロセス名やオプション単独から、外部取得先の指定との組み合わせに変更。|

4688のコマンドライン収集。

## SPL

```spl
index=detection_lab log_type="windows" earliest=-10m@m latest=-5m@m
| where channel="Security" AND event_id=4688
    AND match(process_path, "(?i)(^|[\\\\/])certutil\\.exe$")
    AND match(command_line, "(?i)(^|\\s)[-/](urlcache|verifyctl)\\b")
    AND match(command_line, "(?i)https?://[^\\s\"]+")
| stats count as observed
        min(_time) as first_seen
        max(_time) as last_seen
        values(command_line) as commands
    by host
| eval rule_id="WIN-014", attack_id="T1105"
```

**範囲：** 取得要求を捉える。ダウンロード成功やファイル実行は未判定。
