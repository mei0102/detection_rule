# DNS-007 同じDNS名への低揺らぎ周期照会

同一端末・同一DNS名への照会が12間隔以上続き、30〜300秒周期で揺らぎ10%以下。

|項目|内容|
|---|---|
|対象ログ|DNS|
|必要フィールド|`_time`, `log_type`, `src_ip`, `dns_query`|
|ATT&CK 戦術|[TA0011 Command and Control](https://attack.mitre.org/tactics/TA0011)|
|技法 → サブ技法|[T1071 Application Layer Protocol](https://attack.mitre.org/techniques/T1071) → [T1071.004 DNS](https://attack.mitre.org/techniques/T1071/004)|
|検索|30分窓／5分間隔／5分遅延|
|工夫|長さ・件数とは別に、照会間隔と揺らぎを見る独自相関。|

## SPL

```spl
index=detection_lab log_type="dns" earliest=-35m@m latest=-5m@m
| eval query=lower(rtrim(dns_query,"."))
| where NOT match(query,"[.]arpa$")
| dedup src_ip query _time
| sort 0 _time
| streamstats current=f last(_time) as previous_time by src_ip query
| eval interval=_time-previous_time
| where interval > 0
| stats count as intervals
        avg(interval) as mean_seconds
        stdev(interval) as jitter_seconds
        min(previous_time) as first_seen
        max(_time) as last_seen
    by src_ip query
| where intervals >= 12 AND mean_seconds >= 30 AND mean_seconds <= 300
    AND jitter_seconds/mean_seconds <= 0.1
    AND last_seen-first_seen >= 600
    AND last_seen >= relative_time(now(),"-10m@m")
| eval rule_id="DNS-007", attack_id="T1071.004"
```

**範囲：** キャッシュやTTL更新で周期が変わる。正常なポーリングも一致。
