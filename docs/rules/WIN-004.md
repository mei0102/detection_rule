# WIN-004 ローカルAdministratorsへのメンバー追加

- 状態：experimental / 重要度：medium
- ATT&CK：T1098 / persistence
- 対象ログ：windows
- 必須フィールド：_time, channel, event_id, host, log_type, target_sid
- 窓：300秒（検索範囲全体） / 集約：host
- 指標：count（count以外は異なる値の数） / 閾値：1以上

## 採取の前提

Audit Security Group Management Success。TargetSidは追加先グループのSID。

## 誤検知と調整

承認された権限付与。

## 調査

SubjectUserName、MemberSid、MemberNameを取得して承認と照合し、その後のログオンを確認。

## 限界

Domain Adminsへの4728や他の特権グループは対象外。権限悪用の前兆であり悪性確定ではない。

## 条件（すべてAND）

```json
[
  [
    "channel",
    "eq",
    "Security"
  ],
  [
    "event_id",
    "eq",
    4732
  ],
  [
    "target_sid",
    "eq",
    "S-1-5-32-544"
  ]
]
```
