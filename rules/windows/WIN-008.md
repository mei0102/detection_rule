# WIN-008 新規作成アカウントを直後にAdministratorsへ追加

同一端末で作成されたアカウントが30分以内にAdministratorsへ追加される。

|項目|内容|
|---|---|
|対象ログ|Windows Event|
|必要フィールド|`_time`, `log_type`, `channel`, `event_id`, `host`, `TargetSid`, `MemberSid`, `SubjectUserName`|
|ATT&CK 戦術|[TA0003 Persistence](https://attack.mitre.org/tactics/TA0003), [TA0004 Privilege Escalation](https://attack.mitre.org/tactics/TA0004)|
|技法 → サブ技法|[T1098 Account Manipulation](https://attack.mitre.org/techniques/T1098) → [T1098.007 Additional Local or Domain Groups](https://attack.mitre.org/techniques/T1098/007)|
|検索|35分窓／5分間隔／5分遅延|
|工夫|作成イベントとグループ追加を名前ではなくSIDで相関。|

4720/4732の成功監査。TargetSidとMemberSidはWindows原文の項目。

## SPL

```spl
index=detection_lab log_type="windows" earliest=-40m@m latest=-5m@m
| where channel="Security" AND (event_id=4720 OR (event_id=4732 AND TargetSid="S-1-5-32-544"))
| eval account_sid=if(event_id=4720,TargetSid,MemberSid)
| sort 0 _time
| streamstats time_window=30m current=f
        max(eval(if(event_id=4720,_time,null()))) as created_at
    by host account_sid
| where event_id=4732 AND _time > created_at
    AND _time-created_at <= 1800
    AND _time >= relative_time(now(),"-10m@m")
| table _time host account_sid SubjectUserName created_at
| eval rule_id="WIN-008", attack_id="T1098.007"
```

**範囲：** 端末内で完結する作成・追加のみ。正規の端末セットアップも一致。
