# WIN-023 短時間に多数のRC4サービスチケットを要求

同一ユーザー・送信元が15分で10種類以上の非コンピュータサービス向けRC4チケットを取得。

|項目|内容|
|---|---|
|対象ログ|Windows Event|
|必要フィールド|`_time`, `log_type`, `channel`, `event_id`, `host`, `user`, `src_ip`, `ServiceName`, `TicketEncryptionType`, `Status`|
|ATT&CK 戦術|[TA0006 Credential Access](https://attack.mitre.org/tactics/TA0006)|
|技法 → サブ技法|[T1558 Steal or Forge Kerberos Tickets](https://attack.mitre.org/techniques/T1558) → [T1558.003 Kerberoasting](https://attack.mitre.org/techniques/T1558/003)|
|検索|15分窓／5分間隔／5分遅延|
|工夫|RC4単発利用から、同一主体による取得対象サービスの広がりへ絞込。|

DCの4769。userはTargetUserName、src_ipはIpAddressに対応。

## SPL

```spl
index=detection_lab log_type="windows" earliest=-20m@m latest=-5m@m
| where channel="Security" AND event_id=4769
    AND lower(TicketEncryptionType)="0x17" AND lower(Status)="0x0"
    AND NOT match(ServiceName,"\\$$")
| stats dc(ServiceName) as services
        count as requests
        min(_time) as first_seen
        max(_time) as last_seen
    by user src_ip
| where services >= 10
| eval rule_id="WIN-023", attack_id="T1558.003"
```

**範囲：** 古い正規サービスもRC4を利用する。暗号化チケットの解析成功は不明。
