# DNS-004 DNS ANY問い合わせの宛先集中

同一送信元から同じDNSサーバへ、5分で200回以上・20種類以上のANY問い合わせ。

|項目|内容|
|---|---|
|対象ログ|DNS|
|必要フィールド|`_time`, `log_type`, `src_ip`, `dest_ip`, `dns_query`, `query_type`|
|ATT&CK 戦術|[TA0040 Impact](https://attack.mitre.org/tactics/TA0040)|
|技法 → サブ技法|[T1498 Network Denial of Service](https://attack.mitre.org/techniques/T1498) → [T1498.002 Reflection Amplification](https://attack.mitre.org/techniques/T1498/002)|
|検索|5分窓／5分間隔／5分遅延|
|工夫|宛先だけの件数から、送信元と問い合わせ名の広がりも保持。|

## SPL

```spl
index=detection_lab log_type="dns" earliest=-10m@m latest=-5m@m
| where upper(query_type)="ANY"
| stats count as queries
        dc(dns_query) as names
        min(_time) as first_seen
        max(_time) as last_seen
    by src_ip dest_ip
| where queries >= 200 AND names >= 20
| eval rule_id="DNS-004", attack_id="T1498.002"
```

**範囲：** 増幅攻撃の準備・実行の候補。応答サイズや被害側の可用性低下は未判定。
