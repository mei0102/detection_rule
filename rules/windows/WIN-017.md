# WIN-017 BITSAdminジョブにHTTP転送元を指定

BITSAdminのtransfer／addfile操作にHTTP(S) URLが含まれる。

|項目|内容|
|---|---|
|対象ログ|Windows Event|
|必要フィールド|`_time`, `log_type`, `channel`, `event_id`, `host`, `process_path`, `command_line`|
|ATT&CK 戦術|[TA0002 Execution](https://attack.mitre.org/tactics/TA0002), [TA0003 Persistence](https://attack.mitre.org/tactics/TA0003), [TA0005 Stealth](https://attack.mitre.org/tactics/TA0005)|
|技法 → サブ技法|[T1197 BITS Jobs](https://attack.mitre.org/techniques/T1197)|
|検索|5分窓／5分間隔／5分遅延|
|工夫|ジョブ操作に転送元指定を組み合わせ、状態照会などを除く。|

4688のコマンドライン収集。

## SPL

```spl
index=detection_lab log_type="windows" earliest=-10m@m latest=-5m@m
| where channel="Security" AND event_id=4688
    AND match(process_path, "(?i)(^|[\\\\/])bitsadmin\\.exe$")
    AND match(command_line, "(?i)(^|\\s)/(transfer|addfile)\\b")
    AND match(command_line, "(?i)https?://")
| stats count as observed
        min(_time) as first_seen
        max(_time) as last_seen
        values(command_line) as commands
    by host
| eval rule_id="WIN-017", attack_id="T1197"
```

**範囲：** 正規の配布ジョブも一致。BITS COM API経由の操作は対象外。
