# WIN-020 NetshでWindowsファイアウォールを無効化

netshのfirewall設定変更でstate off／opmode disableを指定する。

|項目|内容|
|---|---|
|対象ログ|Windows Event|
|必要フィールド|`_time`, `log_type`, `channel`, `event_id`, `host`, `process_path`, `command_line`|
|ATT&CK 戦術|[TA0112 Defense Impairment](https://attack.mitre.org/tactics/TA0112)|
|技法 → サブ技法|[T1686 Disable or Modify System Firewall](https://attack.mitre.org/techniques/T1686)|
|検索|5分窓／5分間隔／5分遅延|
|工夫|offという文字列単独ではなく設定変更の構文を条件化。|

4688のコマンドライン収集。

## SPL

```spl
index=detection_lab log_type="windows" earliest=-10m@m latest=-5m@m
| where channel="Security" AND event_id=4688
    AND match(process_path, "(?i)(^|[\\\\/])netsh\\.exe$")
    AND match(command_line, "(?i)\\b(advfirewall|firewall)\\b")
    AND match(command_line, "(?i)\\bset\\b.*\\b(state\\s+off|opmode\\s+(mode\\s*=\\s*)?disable)\\b")
| stats count as observed
        min(_time) as first_seen
        max(_time) as last_seen
        values(command_line) as commands
    by host
| eval rule_id="WIN-020", attack_id="T1686"
```

**範囲：** 保守作業でも一致。GPO・API経由の無効化は対象外。
