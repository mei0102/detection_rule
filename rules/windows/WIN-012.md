# WIN-012 作成から5分以内に削除されたタスク

同一端末・同一TaskNameの作成→削除を5分以内で相関する。

|項目|内容|
|---|---|
|対象ログ|Windows Event|
|必要フィールド|`_time`, `log_type`, `channel`, `event_id`, `host`, `TaskName`|
|ATT&CK 戦術|[TA0002 Execution](https://attack.mitre.org/tactics/TA0002), [TA0003 Persistence](https://attack.mitre.org/tactics/TA0003), [TA0004 Privilege Escalation](https://attack.mitre.org/tactics/TA0004)|
|技法 → サブ技法|[T1053 Scheduled Task/Job](https://attack.mitre.org/techniques/T1053) → [T1053.005 Scheduled Task](https://attack.mitre.org/techniques/T1053/005)|
|検索|10分窓／5分間隔／5分遅延|
|工夫|短命なタスクを作成・削除の順序で識別し、同一名の別端末を混同しない。|

## SPL

```spl
index=detection_lab log_type="windows" earliest=-15m@m latest=-5m@m
| where channel="Security" AND event_id IN (4698,4699)
| sort 0 _time
| streamstats time_window=5m current=f
        max(eval(if(event_id=4698,_time,null()))) as created_at
    by host TaskName
| where event_id=4699 AND _time > created_at
    AND _time-created_at <= 300
    AND _time >= relative_time(now(),"-10m@m")
| eval lifetime_seconds=_time-created_at
| table _time host TaskName created_at lifetime_seconds
| eval rule_id="WIN-012", attack_id="T1053.005"
```

**範囲：** 一時タスクを使う保守でも一致。タスクの実行結果は判断しない。
