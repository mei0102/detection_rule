# FW-002 内部複数ホストへのRDPポート接続許可

- 状態：experimental / 重要度：medium
- ATT&CK：T1021.001 / lateral-movement
- 対象ログ：fw
- 必須フィールド：_time, action, dest_ip, dest_port, dest_zone, log_type, src_ip, src_zone, transport
- 窓：300秒（検索範囲全体） / 集約：src_ip
- 指標：dest_ip（count以外は異なる値の数） / 閾値：10以上

## 採取の前提

内部間通信のFW可視性。internalは組織の資産・ネットワーク定義で付与。

## 誤検知と調整

踏み台・管理ツール・運用者の一括接続。

## 調査

4624 LogonType 10やNDRのRDP識別と照合。許可ログだけで認証成功としない。

## 限界

3389はRDPの代理指標。横移動を証明しない。非標準ポートやFWを通らない通信は見えない。

## 条件（すべてAND）

```json
[
  [
    "transport",
    "eq",
    "tcp"
  ],
  [
    "dest_port",
    "eq",
    3389
  ],
  [
    "action",
    "eq",
    "allow"
  ],
  [
    "src_zone",
    "eq",
    "internal"
  ],
  [
    "dest_zone",
    "eq",
    "internal"
  ]
]
```
