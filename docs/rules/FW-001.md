# FW-001 単一宛先への多数ポート接続試行

- 状態：experimental / 重要度：medium
- ATT&CK：T1046 / discovery
- 対象ログ：fw
- 必須フィールド：_time, dest_ip, dest_port, log_type, src_ip, transport
- 窓：300秒（検索範囲全体） / 集約：src_ip, dest_ip
- 指標：dest_port（count以外は異なる値の数） / 閾値：20以上

## 採取の前提

allow/deny双方のセッションログ。ポートを整数化しNAT前後を区別。

## 誤検知と調整

脆弱性スキャナ、監視、資産探索。

## 調査

action、パケット数、送信元資産、スキャン承認、宛先の応答を確認。

## 限界

5分20ポートの探索候補。低速・分散・同一ポートの横断探索は対象外。通信成功とは限らない。

## 条件（すべてAND）

```json
[
  [
    "transport",
    "eq",
    "tcp"
  ]
]
```
