# WIN-002 Security監査ログの消去

- 状態：experimental / 重要度：medium
- ATT&CK：T1070.001 / defense-evasion
- 対象ログ：windows
- 必須フィールド：_time, channel, event_id, host, log_type
- 窓：300秒（検索範囲全体） / 集約：host
- 指標：count（count以外は異なる値の数） / 閾値：1以上

## 採取の前提

Securityチャネルを中央転送し、消去前後の転送欠損を監視。

## 誤検知と調整

承認済みの保守や検証環境のログ初期化。

## 調査

SubjectUserName、SubjectLogonIdを取得し、作業申請・4624と照合。消去直前のログを保全。

## 限界

1102到着前の転送停止や他チャネル消去は対象外。

## 条件（すべてAND）

```json
[
  [
    "channel",
    "eq",
    "Security"
  ],
  [
    "event_id",
    "eq",
    1102
  ]
]
```
