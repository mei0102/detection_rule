# DNS-006 逆引きDNSによる多数ホスト探索

同じ送信元から5分で50種類以上のPTR逆引き問い合わせ。

|項目|内容|
|---|---|
|対象ログ|DNS|
|必要フィールド|`_time`, `log_type`, `src_ip`, `dns_query`, `query_type`|
|ATT&CK 戦術|[TA0007 Discovery](https://attack.mitre.org/tactics/TA0007)|
|技法 → サブ技法|[T1018 Remote System Discovery](https://attack.mitre.org/techniques/T1018)|
|検索|5分窓／5分間隔／5分遅延|
|工夫|ポート探索とは別に、逆引き要求の種類数からホスト探索を捉える独自ルール。|

## SPL

```spl
index=detection_lab log_type="dns" earliest=-10m@m latest=-5m@m
| where upper(query_type)="PTR"
| eval query=lower(rtrim(dns_query,"."))
| where match(query,"[.](in-addr|ip6)[.]arpa$")
| stats dc(query) as hosts_queried
        count as queries
        min(_time) as first_seen
        max(_time) as last_seen
    by src_ip
| where hosts_queried >= 50
| eval rule_id="DNS-006", attack_id="T1018"
```

**範囲：** 資産管理・メールサーバも一致。問い合わせだけではホストの存在確認成功は不明。
