# NDR-001 長いDNSラベルを持つ多数の異なる問い合わせ

- 状態：experimental / 重要度：medium
- ATT&CK：T1071.004 / command-and-control
- 対象ログ：ndr
- 必須フィールド：_time, dns_query, log_type, protocol, src_ip
- 窓：300秒（検索範囲全体） / 集約：src_ip
- 指標：dns_query（count以外は異なる値の数） / 閾値：20以上

## 採取の前提

クライアントを識別できるDNS問い合わせログ。dns_queryを小文字化し末尾ドット除去。

## 誤検知と調整

CDN、トラッキング、セキュリティ製品。

## 調査

親ドメイン別の件数、エントロピー、応答、プロセス、リゾルバ経由かを確認。

## 限界

DNSトンネルの候補であり確定ではない。DoH/DoTの暗号化、短いラベル、リゾルバ集約で見逃しや誤帰属がある。

## 条件（すべてAND）

```json
[
  [
    "protocol",
    "eq",
    "dns"
  ],
  [
    "dns_query",
    "regex",
    "(^|\\.)[^.]{50,63}(\\.|$)"
  ]
]
```
