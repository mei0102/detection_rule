# WIN-002 Security監査ログの消去

Security監査ログの消去を検知。

|項目|内容|
|---|---|
|対象ログ|Windows Event|
|必要フィールド|`_time`, `channel`, `event_id`, `host`, `log_type`|
|ATT&CK 戦術|[TA0112 Defense Impairment](https://attack.mitre.org/tactics/TA0112)|
|技法 → サブ技法|[T1685 Disable or Modify Tools](https://attack.mitre.org/techniques/T1685) → [T1685.005 Clear Windows Event Logs](https://attack.mitre.org/techniques/T1685/005)|

## SPL

```spl
index=detection_lab log_type="windows" earliest=-10m@m latest=-5m@m
| where channel="Security"
    AND event_id=1102
| stats count as observed
        min(_time) as first_seen
        max(_time) as last_seen
    by host
| where observed >= 1
| eval rule_id="WIN-002", attack_id="T1685.005"
```

**範囲：** Securityの1102のみ。他チャネルの消去やログ転送停止は対象外。
