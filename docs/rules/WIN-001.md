# WIN-001 EncodedCommandを使うPowerShell

- 状態：experimental / 重要度：medium
- ATT&CK：T1059.001 / execution
- 対象ログ：windows
- 必須フィールド：_time, channel, command_line, event_id, host, log_type, process_path
- 窓：300秒（検索範囲全体） / 集約：host
- 指標：count（count以外は異なる値の数） / 閾値：1以上

## 採取の前提

Audit Process CreationとInclude command line in process creation eventsを有効化。

## 誤検知と調整

構成管理・管理者の正規スクリプト。署名、親プロセス、利用者、実行時間を組み合わせて除外する。

## 調査

元の4688、親プロセス、実行者、後続通信を確認。Base64は文字列として復号し、実行しない。

## 限界

名前変更、インプロセス実行、Unicodeスイッチは対象外。エンコードだけでは悪性と断定できない。

## 条件（すべてAND）

```json
[
  [
    "channel",
    "eq",
    "Security"
  ],
  [
    "event_id",
    "eq",
    4688
  ],
  [
    "process_path",
    "regex",
    "(?i)(^|[\\\\/])(powershell|pwsh)\\.exe$"
  ],
  [
    "command_line",
    "regex",
    "(?i)(^|\\s)-(e|en|enc|enco|encod|encode|encoded|encodedc|encodedco|encodedcom|encodedcomm|encodedcomma|encodedcomman|encodedcommand)\\s+\\S+"
  ]
]
```
