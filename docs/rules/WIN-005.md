# WIN-005 新規スケジュールタスクの作成

- 状態：experimental / 重要度：low
- ATT&CK：T1053.005 / persistence
- 対象ログ：windows
- 必須フィールド：_time, channel, event_id, host, log_type
- 窓：300秒（検索範囲全体） / 集約：host
- 指標：count（count以外は異なる値の数） / 閾値：1以上

## 採取の前提

Audit Other Object Access Events Success。TaskContent XMLも保存。

## 誤検知と調整

ソフト更新や運用のタスク登録。高頻度環境ではハンティング用途から開始。

## 調査

TaskContentのAction、実行アカウント、TaskName、作成者、実体ファイルを確認。

## 限界

全作成を拾う低特異度の可視化ルール。悪性判定にはタスク内容と資産情報が必要。更新4698以外は対象外。

## 条件（すべてAND）

```json
[
  [
    "channel",
    "eq",
    "Security"
  ],
  [
    "event_id",
    "eq",
    4698
  ]
]
```
