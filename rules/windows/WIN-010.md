# WIN-010 書込可能パスやシェルを使うサービス登録

サービスの実行パスがTemp／Public配下、またはスクリプト実行用プロセス。

|項目|内容|
|---|---|
|対象ログ|Windows Event|
|必要フィールド|`_time`, `log_type`, `channel`, `event_id`, `host`, `Provider_Name`, `ImagePath`, `ServiceName`|
|ATT&CK 戦術|[TA0003 Persistence](https://attack.mitre.org/tactics/TA0003), [TA0004 Privilege Escalation](https://attack.mitre.org/tactics/TA0004)|
|技法 → サブ技法|[T1543 Create or Modify System Process](https://attack.mitre.org/techniques/T1543) → [T1543.003 Windows Service](https://attack.mitre.org/techniques/T1543/003)|
|検索|5分窓／5分間隔／5分遅延|
|工夫|サービス作成のうち、書込可能パスまたはインタープリターの使用を抽出。|

Systemの7045。ImagePathはサービスの実行コマンド。

## SPL

```spl
index=detection_lab log_type="windows" earliest=-10m@m latest=-5m@m
| where channel="System" AND event_id=7045
    AND Provider_Name="Service Control Manager"
    AND (match(ImagePath, "(?i)[\\\\/](Windows[\\\\/]Temp|Users[\\\\/]Public|AppData[\\\\/](Local|Roaming))[\\\\/]")
         OR match(ImagePath, "(?i)(^|[\\\\/\\s\"])(powershell|pwsh|cmd|mshta|wscript|cscript)\\.exe(\\s|\"|$)"))
| stats count as observed
        min(_time) as first_seen
        max(_time) as last_seen
        values(ImagePath) as service_commands
    by host ServiceName
| eval rule_id="WIN-010", attack_id="T1543.003"
```

**範囲：** 正規インストーラも一致。記録されたパスだけでは実行成功は不明。
